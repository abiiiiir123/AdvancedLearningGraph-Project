How does the extractor work?

1) A gazetteer of … canonical skills (the dataset's own technology vocabulary, grouped in 11 categories); 2) … aliases normalised to one name (PowerBI → power bi, sklearn → scikit-learn); 3) one compiled regular expression, longest match first, with token boundaries that keep c++, c#, node.js intact; 4) ambiguity rules: R, C, Go, Word, Spring… only match their case-sensitive technical spelling, and R&D / C-level are rejected.
Limitations: no deep context understanding ("Excel at teamwork" matches Excel), unseen technologies are missed, and each skill has a single category.
